# Hi, I'm Özgün 👋

Data engineer at [ADIN](https://adin.ai), where I build the data platform behind
marketing analytics: pipelines that pull ad-platform data into ClickHouse,
serverless services on AWS, and AI agents that work on top of that data.

### What I work on

- **Data pipelines**: campaign data from Meta, Google, LinkedIn, CM360, Adform and others into ClickHouse
- **Cloud**: AWS Lambda, ECS, EventBridge, S3, RDS
- **AI agents**: LLM-based tools for analytics and engineering teams, including [AI Office](https://github.com/ozgunakin/ai-office-releases)
- **Platform**: Vue 3 front end and the APIs behind it
